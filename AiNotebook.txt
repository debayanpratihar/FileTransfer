Step 2: Create a CLAUDE.md file
This is the most important file. Claude Code automatically reads it every session if it's in the project root. 

Example:

# AI Notebook

This project is a production-quality Android application.

## Tech Stack

- Kotlin
- Jetpack Compose
- MVVM
- Room
- DataStore
- OkHttp
- Kotlin Coroutines
- Hilt
- llama.cpp
- ML Kit

## Coding Rules

- Never use XML layouts.
- Use Compose only.
- Follow Clean Architecture.
- Keep UI and business logic separate.
- Every feature must include ViewModel.
- Never create God classes.
- Write production-ready code.
- Keep functions under 40 lines where practical.
- Add KDoc to all public classes.

## Project Goal

Create an offline AI notebook where AI writes directly on the notebook beside the user's handwriting.

AI must run locally.

Internet is only used for downloading AI models.
